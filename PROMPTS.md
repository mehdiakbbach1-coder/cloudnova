# Development Prompts

This document summarizes the three prompts used to guide the CloudNova landing page work.

## Initial Prompt

> Create a professional, responsive, static landing page for the fictional cloud computing company CloudNova in the existing Vue 3 + Vite project. Introduce the company and its services for developers, startups, IT professionals, and small businesses. Include navigation, a hero with an infrastructure visual, three service cards, key features, three clearly fictional sample pricing plans, an about section, sample contact details, and a footer. Use a premium dark navy, blue, and purple design with clear typography, rounded cards, icons, and subtle interactions. Use Vue single-file components; do not add a backend, database, login, multiple pages, or unnecessary dependencies. Inspect the project before making changes.

**What it improved:** Replaced the starter screen with a complete single-page CloudNova introduction and responsive visual design using the existing Vue and Vite setup.

## Follow-up Prompt 1

> Review the landing page and improve visual hierarchy and presentation. Refine the hero, section spacing and alignment, service-card distinction, pricing comparison, main calls to action, and typography. Keep the existing dark navy, blue, and purple theme, sections, content, and responsive behavior.

**What it improved:** Strengthened hero emphasis and calls to action, clarified differences between service cards, aligned pricing cards for comparison, and improved text sizing and spacing.

## Follow-up Prompt 2

> Refine the landing page for usability, accessibility, and responsive behavior. Add smooth section navigation, clear hover and focus states, appropriate ARIA labels, and reliable mobile-menu behavior. Organize sample contact information and check typography and card layouts on narrow screens. Respect reduced-motion preferences while preserving the existing visual identity, sections, and content. Do not add a backend or unnecessary dependencies.

**What it improved:** Added accessible section labels and focus treatment, made the mobile menu easier to operate, clarified contact information, checked narrow viewport layouts, and honored reduced-motion settings.
