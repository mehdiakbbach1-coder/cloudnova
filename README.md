# CloudNova

CloudNova is a responsive, single-page landing site introducing a fictional cloud computing platform. It presents the platform’s services and features, provides sample pricing, and gives visitors sample contact information.

The page is intended for software developers, startups, IT professionals, and small businesses.

## Page sections and features

- **Navigation:** Links to Home, Services, Features, Pricing, About, and Contact.
- **Hero:** Introductory headline, platform description, calls to action, and a cloud infrastructure illustration.
- **Services:** Cloud computing, cloud storage, and cloud hosting cards.
- **Features:** Security, scalability, reliability, and high availability.
- **Pricing:** Starter, Professional, and Enterprise plans. Prices are fictional sample data for illustrative purposes.
- **About:** Introduction to the fictional CloudNova company.
- **Contact:** Sample email and location information.
- **Footer:** Copyright notice and section navigation.

The mobile navigation can be opened and closed with its menu button, and closes when a section is selected, when clicking outside the header, when pressing Escape, or when switching to a desktop-width viewport. The page includes visible keyboard focus styles and respects reduced-motion preferences.

## Technologies

- Vue 3 single-file components
- Vite
- JavaScript
- CSS

## Requirements

- Node.js and npm installed.
- A modern browser.

## Installation

From the project root, install the project dependencies:

```sh
npm install
```

## Run locally

Start the Vite development server:

```sh
npm run dev
```

Open the local URL printed by Vite in your browser.

## Production build

Create an optimized production build:

```sh
npm run build
```

Vite writes the generated site to the `dist/` directory. To serve that build locally, run:

```sh
npm run preview
```

## Fictional content notice

CloudNova is a fictional cloud computing platform created for a front-end design assignment. Its service descriptions, contact details, and pricing are sample information, not a real offer or contact channel. All listed prices are fictional.
